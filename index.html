API Documentation

This API allows CRUD operations for movies, series, and songs stored dynamically in a JSON file.

Endpoints

  • GET /movies: Retrieve movies.
  • POST /movies: Add a movie (JSON format).
  • PUT /movies: Update the first movie.
  • DELETE /movies: Delete the first movie.

Example Usage

curl -X POST http://localhost:3000/movies \
     -H "Content-Type: application/json" \
     -d '{"title": "Inception", "year": 2010}'
